03 fragment shader

Fragment Shader Fundamentals

Build-Along Milestone: You can trace one shaded pixel in scene.frag from interpolated varyings through texture fetches to HDR outColor.

You will learn:

  • How rasterization delivers fragments and what interpolation guarantees.
  • Sample from sampler2DArray with per-draw layer selection.
  • Structure a forward PBR lighting function with directional, punctual, and IBL terms.
  • Handle sky rendering as a special shading path.

1. The Problem We Are Solving

The fragment shader runs once per fragment (coverage sample) generated by rasterizing triangles. It receives interpolated values from the vertex shader — position, normal, UVs — and must produce a color written to the color attachment (and optionally depth).

Spark's scene.frag is not a tutorial gl_FragColor = vec4(1,0,0,1) — it implements:

  • Sky modes (procedural gradient, equirect texture, ground plane)
  • Metallic-roughness PBR with GGX specular
  • Toon and unlit shading models
  • Directional shadows with cascades
  • Clustered point and spot lights
  • Image-based lighting (IBL)

You will not implement all of this in one sitting. This chapter teaches the structure: inputs, texture binding, shading dispatch, and HDR output — so each feature in Parts IV–VII slots into a place you already understand.

2. Core Concepts

Fragments vs vertices

Triangle (3 vertices)
→ rasterizer (fixed function)
    → N fragments (many per triangle)
        → fragment shader (programmable)
            → blend / depth test → framebuffer
Property Vertex shader Fragment shader
Invocations Once per vertex Once per covered sample
Inputs Vertex attributes Interpolated varyings + gl_FragCoord
Outputs gl_Position, varyings outColor, (no gl_FragDepth in Spark default)
Derivatives N/A dFdx, dFdy available for mip selection

Perspective-correct interpolation divides varyings by w during rasterization, then multiplies back — so vWorldPos stays linear in world space across the triangle when projected correctly.

Matching vertex outputs to fragment inputs

scene.frag mirrors scene.vert locations:

layout(location = 0) in vec3 vWorldPos;
layout(location = 1) in vec3 vNormal;
layout(location = 4) flat in int vTextureLayer;

Type, location, and flat qualification must match exactly between stages. SPIR-V linking catches mismatches at pipeline creation time.

Descriptor bindings in the fragment stage

layout(set = 0, binding = 1) uniform sampler2DArray sceneTextures;
#include "scene_ubo.glsl"   // set 0, binding 0
Binding Type Stage usage
0 SceneUBO (std140) Camera, lights, shadows, clusters
1 sampler2DArray Albedo, normal, MR, emissive layers
2 SSBO skin bones Vertex only in Spark
3+ SSBO lights Fragment clustered lookup

The fragment shader performs the heavy texture and lighting work — keep vertex shader lean.

Texture array layer selection

Spark packs many material textures into one 2DArray image to reduce descriptor churn:

int layer = clamp(vTextureLayer, 0, 15);
vec4 albedoTex = texture(sceneTextures, vec3(vTexCoord, float(layer)));

vTextureLayer is flat — all fragments in a draw use the same layer. Per-draw push.textureLayer sets the layer from C++.

Normal mapping and TBN

When push.normalMapLayer >= 0, the fragment shader builds a tangent-bitangent-normal matrix from vTangent, vNormal, and tangent handedness (vTangent.w). It samples the normal map, transforms to world space, and renormalizes. This is why the vertex shader transports both normal and tangent.

PBR microfacet model (overview)

Spark's lit path uses Cook-Torrance specular with GGX normal distribution:

float D_GGX(float NdotH, float roughness) { /* ... */ }
float G_Smith(float NdotV, float NdotL, float roughness) { /* ... */ }
vec3 F_Schlick(float cosTheta, vec3 F0) { /* ... */ }
Symbol Meaning
N Shading normal (world)
V View vector toward camera
L Light vector
H Half vector between V and L
F0 Fresnel at normal incidence (dielectric 0.04, metal = albedo)

Diffuse uses Lambertian term modulated by (1 - metallic); specular uses F * D * G / (4 * NdotV * NdotL).

Full derivations live in Part IV; here the lesson is composition: helper functions at file scope, main() orchestrates material resolve → lighting → tone-ready HDR output.

Shading model dispatch

push.shadingModel selects the BRDF path:

Value Behavior
0 Metallic-roughness PBR
1 Toon (banded diffuse + rim)
2 Unlit (albedo emissive only)

Dispatch keeps one shader module and one pipeline for many material types — alternative is shader variants (Chapter 10).

Sky as a fragment special case

When push.skyMode != 0, main() early-outs into sky shading:

vec2 ndc = vec2(sx * 2.0 - 1.0, sy * 2.0 - 1.0);
vec4 farH = ubo.invViewProj * vec4(ndc, 1.0, 1.0);
vec3 dir = normalize(farW - cam);

Using gl_FragCoord and invViewProj reconstructs a per-pixel view ray. Interpolated vWorldPos from a large sky dome would curve incorrectly when the camera rotates — Spark's comment in the shader explains this bug class explicitly.

HDR output

Scene pass renders to floating-point color attachment. outColor can exceed 1.0 — sun disks, bright emissive. Tonemapping happens in a later pass (tonemap.frag, Part VIII). Do not clamp to [0,1] in scene.frag unless debugging.

3. Design Decisions

Each decision below references a concept from Section 2 and shows where Spark applies it.

sampler2DArray atlas

Concept: Texture array layer selection

Decision: One binding for all material textures, layer per draw

Why: Fewer descriptor updates; texture arrays widely supported on Vulkan 1.0 hardware.

In Spark: scene.frag binding 1; CPU assigns textureLayer per SceneDrawItem.

Includes for lights and IBL

Concept: PBR composition

Decision: #include "clustered_lights.glsl", ibl.glsl, punctual_shadows.glsl

Why: Keep main() readable; share code with shadow passes; single source for light struct layout.

In Spark: Chapter 6 covers include graph; CMake DEPENDS lists all headers.

Shading model integer, not uber-shader #ifdef

Concept: Shading model dispatch

Decision: Runtime branch on push.shadingModel

Why: One SPIR-V module, three pipelines (opaque, transparent, sky) — avoids combinatorial shader permutations at build time.

In Spark: SceneShadingModel.hpp documents enum values.

Sky ray from invViewProj

Concept: Sky special case

Decision: Reconstruct direction per fragment, not from varyings

Why: Correct equirect stability when camera rotates; documented real bug if using vWorldPos.

In Spark: scene.frag lines 383–423.

No manual depth output

Concept: Fragments vs vertices

Decision: Depth from rasterizer only (gl_FragCoord.z); sky pipeline disables depth test

Why: Simpler; transparent pass sets depthWriteEnable = false instead of shader depth tricks.

In Spark: VulkanScenePipeline depth stencil variants.

4. Implementation Walkthrough

Spark Files We Touch This Chapter

  • shaders/scene.frag
  • shaders/scene.vert (varying contract)
  • shaders/clustered_lights.glsl, ibl.glsl, color_space.glsl
  • src/spark/render/scene/VulkanScenePipeline.cpp (blend/depth variants)

Step 1 — Solid color from varyings

Temporarily replace main() body:

outColor = vec4(vNormal * 0.5 + 0.5, 1.0);

Rebuild SPIR-V, run demo — confirms interpolation and stage linkage.

Step 2 — Texture sample

Bind a known checkerboard to layer 0. Output:

outColor = texture(sceneTextures, vec3(vTexCoord, 0.0));

If stripes appear, check UV orientation (stbi flip) and VkSampler address mode.

Step 3 — Directional light only

Comment out clustered and IBL includes. Implement NdotL diffuse with ubo.lightDir and ubo.lightColor:

vec3 N = normalize(vNormal);
vec3 L = normalize(-ubo.lightDir.xyz);
float diff = max(dot(N, L), 0.0);
vec3 col = diff * ubo.lightColor.rgb * ubo.lightColor.a;
outColor = vec4(col, 1.0);

Step 4 — Add specular term

Introduce V, H, and D_GGX from Spark's helpers. Compare roughness 0.1 vs 0.9 on a sphere.

Step 5 — Restore includes incrementally

Re-enable punctual_shadows.glsl, then clustered_lights.glsl, then ibl.glsl — one per build, verifying each addition.

Step 6 — Sky mode test

Draw a sky dome with skyMode = 1 (procedural). Rotate camera — gradient should stay horizon-locked. Switch to equirect layer and confirm no swimming.

5. How This Connects to the Rest of Your Engine

Chapter 4 aligns SceneUniformGpu with ubo fields used here. Chapter 7 explains depth state that orders opaque before transparent. Part IV deep-dives texture formats and light structs. Part VIII tonemaps HDR outColor for display.

The fragment shader is where perceived quality lives — vertex work is invisible if shading is wrong.

6. Pitfalls and Debugging

  • Black mesh — wrong descriptor set bound, or textureLayer = -1 with broken fallback albedo path.
  • Faceted lighting — forgot normalize(vNormal) after interpolation; or normal map TBN not orthonormalized.
  • Fireflies — specular division without max(denom, 1e-6) guard; Spark clamps denominators.
  • Gamma wrong — albedo textures are sRGB; use sparkSrgbToLinear from color_space.glsl before lighting.
  • Shader link error — varying type mismatch between vert and frag; check flat on vTextureLayer.

7. Exercises

  1. Visualize vRoughness as grayscale — confirm per-vertex interpolation smoothness on a low-poly sphere.
  2. Replace PBR with Lambert only — measure FPS difference (usually small; fragment bound on fill rate).
  3. Output length(fwidth(vTexCoord)) — see where mip filtering would help (Part IV).
  4. Break invViewProj on CPU — observe sky ray corruption vs mesh lighting (meshes still use varyings).
  5. Add a debug mode: if (push.shadingModel == 99) outColor = vec4(1,0,1,1); — confirm push reaches fragment stage.

Summary

scene.frag receives interpolated world-space material inputs, samples sceneTextures by layer, and evaluates forward lighting with optional shadows, clusters, and IBL. Sky modes bypass mesh lighting and reconstruct view rays from invViewProj. Output is linear HDR color for a later tonemap pass. Build incrementally: normals → textures → directional → full PBR → includes.
